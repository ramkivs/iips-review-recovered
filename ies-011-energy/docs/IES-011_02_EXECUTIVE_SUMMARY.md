# Purpose

High-level summary of the Energy Sector Engine for reviewers.

# Summary

- **Sector economics:** commodity price × volume; value chain segments (upstream/midstream/downstream/integrated/renewables/utilities).
- **Core metrics:** production growth, lifting cost, reserve replacement, realized price, EBITDA margin, leverage, ROCE, transition mix.
- **Methodology:** deterministic band→score→pillar→composite→verdict, calibrated by value-chain segment + commodity exposure.
- **Cyclicality:** risk via calibration; valuation normalized across the cycle.
- **Moat:** reserves, cost position, scale/infrastructure, technical capability (→ ontology Moat).
- **Overrides:** price collapse, cost blowout, reserve write-down, leverage breach, transition/stranded-asset.
- **Platform-neutral:** differences via methodology + calibration, no platform changes.

# Acceptance basis

Independent implementation must reproduce the same composite + verdict from the same inputs + calibration (Normative Calculation Appendix D15).
