# Purpose

Models how energy businesses create, earn, and compound value.

# 1. Value creation

- **High-quality, long-life reserves** (upstream) and assets (power/utilities).
- **Low-cost position** — lifting cost / cash cost advantage.
- **Capital discipline** — counter-cyclical capex, sustaining vs growth.
- **Reserve/asset replacement** — replacing depletion at favorable cost.
- **Diversified / integrated cash flows** across commodity and segment.
- **Energy transition positioning** — gas/renewables exposure.
- **Strong balance sheet** to weather price cycles.

# 2. Value destruction

- Commodity price collapse.
- Cost overruns / project delays.
- Reserve write-downs / impairments.
- Over-leverage.
- Pro-cyclical over-investment.
- Stranded assets (transition).

# 3. Value chain economics

Per Energy Value Chain Position (§11 of Methodology Principles): different drivers/risks/quality metrics per segment → different calibration profiles, common scoring engine.

# 4. Commodity exposure classification

Price taker / partial hedger / regulated return / contracted revenue / diversified.
