# Purpose

Documents the data sources that inform the energy methodology and reference assets (Phase 3).

# 1. Sources

| Source | Use |
|---|---|
| Company financial reports (public) | revenue, EBITDA, leverage, ROCE, FCF |
| Reserves reports (SEC/PRMS) | reserves, production, reserve life |
| Commodity price data | realized price, cycle context |
| Operator production/cost disclosures | lifting cost, production growth |
| Transition/disclosure reports | renewables mix, carbon exposure |
| Regulatory/licensing records | compliance context |

# 2. Methodology data (golden dataset, Phase 3)

- Representative energy providers across value-chain segments + commodity exposures.
- Deterministic, versioned, evidence-backed.

# 3. Data provenance

Every reference data item carries source + version, so outputs are reproducible and evidence-backed.
