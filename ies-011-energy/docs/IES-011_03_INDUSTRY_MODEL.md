# Purpose

Describes the energy industry structure that the methodology models.

# 1. Value chain

```text
Upstream (E&P) → Midstream (transport/processing/storage) → Downstream (refining/marketing) → Power generation → Retail/utilities
```

# 2. Segments

| Segment | Description |
|---|---|
| Upstream (E&P) | exploration + production (oil/gas) |
| Midstream | pipelines, LNG, storage, processing |
| Downstream | refining, marketing, petrochemicals |
| Integrated | diversified upstream + downstream |
| Oilfield Services | drilling/services to producers |
| Independent Power Producers (IPP) | power generation |
| Regulated Utilities | rate-regulated power/gas |
| Renewables | solar/wind/clean generation |

# 3. Commodity exposure

- Oil, natural gas, electricity, LNG, coal, carbon.
- Commodity Exposure Classification: price taker, partial hedger, regulated return, contracted revenue, diversified.

# 4. Cyclicality

- High commodity-price cyclicality (structural); seasonal demand patterns.
- Modeled via calibration/risk; valuation normalized across the cycle.
