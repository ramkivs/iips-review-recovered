# Purpose

High-level summary of the Utilities Sector Engine for reviewers.

# Summary

- **Sector economics:** regulated rate-base × allowed return; capital-intensive infrastructure.
- **Core metrics:** rate base growth, allowed ROE, FFO/Debt, O&M efficiency, demand growth, reliability, transition capex.
- **Methodology:** deterministic band→score→pillar→composite→verdict, calibrated by regulated vs merchant + segment.
- **Regulatory quality:** constructive vs adversarial; regulatory lag is a leading signal.
- **Moat:** regulated monopoly/rate-base (→ ontology Moat).
- **Overrides:** adverse rate case, regulatory lag, capex overrun, stranded asset, leverage breach.
- **Platform-neutral:** differences via methodology + calibration, no platform changes.

# Acceptance basis

Independent implementation must reproduce the same composite + verdict from the same inputs + calibration (Normative Calculation Appendix D15).
