# Purpose

Describes the utilities industry structure that the methodology models.

# 1. Value chain

```text
Generation → Transmission → Distribution → Retail; Gas distribution/midstream; Water/sewerage
```

# 2. Segments

| Segment | Description |
|---|---|
| Regulated Electric | generation/transmission/distribution, rate-base |
| Gas Distribution | gas distribution/LNG |
| Water Utilities | water/sewerage |
| IPP / Merchant | competitive generation (price/merchant) |
| Multi-utility | combined electric/gas/water |

# 3. Business models

- **Regulated-return** — rate base × allowed return (primary).
- **Merchant/competitive** — IPP, price exposure.
- **Vertically-integrated** — regulated + merchant mix.

# 4. Regulatory structure

- Rate regulation (rate base, allowed ROE, cost recovery) — the defining feature.
- Public utility commissions, federal/state regulators, environmental/reliability/safety.
