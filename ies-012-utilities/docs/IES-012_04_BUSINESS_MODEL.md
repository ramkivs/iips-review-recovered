# Purpose

Models how utilities businesses create, earn, and compound value.

# 1. Value creation

- **Rate-base growth** (regulated asset base expansion) that compounds.
- **Constructive regulatory relationships** — allowed-return stability, low regulatory lag.
- **Recoverable investment quality** — approved, recoverable capex.
- **Operating efficiency** — O&M control, reliability.
- **Balance-sheet resilience** — FFO/Debt, investment-grade.
- **Transition positioning** — grid/electrification investment (recoverable).

# 2. Value destruction

- Adverse rate cases (disallowances, low allowed ROE).
- Regulatory lag (unrecovered cost inflation).
- Capex overruns.
- Stranded assets (transition).
- Over-leverage.
- Reliability/operational failures (penalties).

# 3. Regulatory economics

Rate base × allowed return; capital recovery via rate base; rate-case lifecycle (per Regulated Infrastructure Common Principles + Regulatory Framework & Rate-Case Lifecycle).

# 4. Asset health

Reliability (SAIDI/SAIFI), asset age, maintenance, replacement, deferred maintenance, resilience (per Reliability & Asset Health Framework).
