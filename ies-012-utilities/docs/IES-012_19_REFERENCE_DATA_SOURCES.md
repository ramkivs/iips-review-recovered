# Purpose

Documents the data sources that inform the utilities methodology and reference assets (Phase 3).

# 1. Sources

| Source | Use |
|---|---|
| Company financial reports (public) | revenue, EBITDA, leverage, ROE, FFO |
| Regulatory filings / rate-case documents | allowed ROE, rate base, cost recovery |
| Operator disclosures | reliability (SAIDI), O&M, demand |
| PUC / regulator publications | regulatory posture, rate-case outcomes |
| Transition/disclosure reports | grid/renewables capex |

# 2. Methodology data (golden dataset, Phase 3)

- Representative utilities providers across segments + regulated/merchant models.
- Deterministic, versioned, evidence-backed.

# 3. Data provenance

Every reference data item carries source + version, so outputs are reproducible and evidence-backed.
