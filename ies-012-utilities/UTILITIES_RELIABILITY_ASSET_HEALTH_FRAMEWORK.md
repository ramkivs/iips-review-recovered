# IES-012 — Reliability & Asset Health Framework

**Standard:** IES-012 — Utilities Sector Engine
**Phase:** 2 — Engineering Standard (conceptual)
**Version:** 1.0
**Date:** 2026-08-08
**Status:** METHODOLOGY-LEVEL FRAMEWORK

> **Purpose.** Utilities differ from most industries because long-term value depends heavily on infrastructure reliability. This framework distinguishes the concepts feeding methodology principles + calibration inputs.

---

## 1. Reliability & asset health concepts

| Concept | Description |
|---|---|
| **SAIDI / SAIFI** (where applicable) | System Average Interruption Duration/Frequency Index — reliability metrics |
| **Outage frequency** | number/likelihood of service interruptions |
| **Asset age profile** | distribution of infrastructure asset ages |
| **Maintenance effectiveness** | how well O&M preserves asset condition |
| **Replacement cycle** | cadence of asset replacement/refurbishment |
| **Deferred maintenance risk** | cost/risk of postponed maintenance |
| **Resilience investment** | capex for storm/climate resilience |

## 2. Use in methodology

- **Reliability** is a quality + operating-efficiency dimension (reliability drives allowed returns/penalties).
- **Asset age + deferred maintenance** are risk inputs (aging infrastructure → higher risk).
- **Replacement cycle + resilience investment** are growth/capex inputs (recoverable investment).
