# Purpose

Models how consumer businesses create, earn, and compound value.

# 1. Value creation

- **Brand equity + pricing power** — raise prices without losing volume.
- **Demand durability** — repeat/staple demand.
- **Distribution reach** — shelf space, channels, DTC.
- **Customer loyalty / LTV** — recurring demand.
- **Innovation pipeline** — sustained relevance + premiumization.
- **Margin resilience** — input-cost pass-through.
- **Efficient capital allocation** — buybacks/dividends/reinvestment.

# 2. Value destruction

- Brand erosion / category disruption.
- Input-cost squeeze without pricing power.
- Channel loss / distribution decline.
- Over-leverage / value-destructive M&A.
- Share loss / market-share erosion.
- Innovation failure.

# 3. Brand flywheel

Brand → loyalty → pricing power → reinvestment → brand (per Consumer Demand & Brand Flywheel + Portfolio Architecture).

# 4. Portfolio architecture

Flagship brands, premium vs value, category/geographic/channel diversification, private-label exposure, innovation cadence, portfolio rationalization.
