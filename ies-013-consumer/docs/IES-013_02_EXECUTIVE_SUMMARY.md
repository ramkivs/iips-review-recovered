# Purpose

High-level summary of the Consumer Sector Engine for reviewers.

# Summary

- **Sector economics:** brand-driven value creation; staples (defensive) vs discretionary (cyclical).
- **Core metrics:** revenue growth, pricing power/volume mix, brand/loyalty, margin resilience, distribution/channel mix, FCF yield/capital return, market share.
- **Methodology:** deterministic band→score→pillar→composite→verdict, calibrated by segment (staples/discretionary/luxury) + business model.
- **Brand moat:** brand + pricing power + distribution + loyalty (→ ontology Moat).
- **Overrides:** brand erosion, category disruption, input-cost squeeze, channel loss, leverage breach.
- **Platform-neutral:** differences via methodology + calibration, no platform changes.

# Acceptance basis

Independent implementation must reproduce the same composite + verdict from the same inputs + calibration (Normative Calculation Appendix D15).
