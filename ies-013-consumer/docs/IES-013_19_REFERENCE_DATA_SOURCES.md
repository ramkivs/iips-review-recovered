# Purpose

Documents the data sources that inform the consumer methodology and reference assets (Phase 3).

# 1. Sources

| Source | Use |
|---|---|
| Company financial reports (public) | revenue, EBITDA, leverage, ROIC, FCF |
| Brand/consumer disclosures | brand loyalty, market share |
| Operator/distribution data | channel mix, DTC share, innovation |
| Market/consumer surveys | brand equity, repeat purchase |
| Regulatory/licensing records | compliance context |

# 2. Methodology data (golden dataset, Phase 3)

- Representative consumer providers across segments (staples/discretionary/luxury) + business models.
- Deterministic, versioned, evidence-backed.

# 3. Data provenance

Every reference data item carries source + version, so outputs are reproducible and evidence-backed.
