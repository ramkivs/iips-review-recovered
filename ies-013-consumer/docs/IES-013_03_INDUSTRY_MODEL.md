# Purpose

Describes the consumer industry structure that the methodology models.

# 1. Segments

| Segment | Description | Cyclicality |
|---|---|---|
| Staples | food/beverage, household, personal care | Defensive |
| Discretionary | apparel, durables, autos, restaurants | Cyclical |
| Luxury | premium brands | Moderate-cyclical |

# 2. Business models

| Model | Description |
|---|---|
| Branded manufacturer | owns brands + manufacturing |
| Retailer | sells consumer goods |
| Restaurant/Franchise | foodservice + franchising |
| DTC | direct-to-consumer |
| Multi-brand | multiple brands/portfolio |

# 3. Value chain

```text
R&D/branding → sourcing/manufacturing → distribution/retail → consumer demand
```

# 4. Demand drivers

- Consumer demand, disposable income, pricing power, brand loyalty, distribution, penetration.
