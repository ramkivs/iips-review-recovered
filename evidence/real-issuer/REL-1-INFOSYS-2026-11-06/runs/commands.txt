# REL-1 — commands actually run

Working directory `frontend/` unless stated. `tsx` and `vitest` come from `npm ci` in `frontend/`; the ingestion
CLI comes from `iips-platform/` (`npm ci` there too). Nothing below touches the network.

Paths under `/tmp/rel1/**` are ephemeral. Everything a reader needs to reproduce the run is committed in this
bundle: the inputs (`ingest-input/`, `identity/`), the dataset the run consumed (`dataset/`, `dataset-v1/`), the
artifacts and payloads (`runs/`, `artifact/`), and the digests (`digests.json`).

## 0 — dependency install (both packages, once per session)

    cd iips-platform && npm ci --no-audit --no-fund --strict-ssl=false
    cd ../frontend  && npm ci --no-audit --no-fund --strict-ssl=false

## 1 — ingest the filed disclosures into an IID-0 dataset (snapshot v1)

    cd iips-platform
    npx tsx src/investment/cli/ingest.ts \
      --input       ../evidence/real-issuer/REL-1-INFOSYS-2026-11-06/ingest-input \
      --dataset-dir /tmp/rel1/data/investment/dataset \
      --now 2026-11-06T00:00:00.000Z

Observed: no `ERROR` and no `WARN` line, `issues.json` written as `[]`.

    datasetVersion sha256:9be1a83ef198393b97465e104bef9270287bdc01a400c140a9f70927cdfa96e0

Coverage printed by the same run: line items 52, Technology `G2_PARTIAL` usable 2 / withheld 2, statements
87.5 %, metrics 0 % (`OPERATING_METRIC_MISSING`).

## 2 — stage the IID-1 identity directory beside the dataset

    cp evidence/real-issuer/REL-1-INFOSYS-2026-11-06/identity/*.json /tmp/rel1/data/investment/identity/

The three files are byte-identical to the copies committed in `identity/` (see `digests.json`).

## 3 — owner carrier (Art. XI owner context, required by the artifact CLI)

`frontend/server/reports-owner-carrier.ts` publishes `CANONICAL_REPORTS_CARRIER_TEXT`; the carrier file must
contain exactly those bytes (sha256 `b1b78809d1c8…`, 384 B). Written once, committed as `runs/owner-carrier.json`.

## 4 — generate → assess → compose → validate → persist → verify (artifact v1)

    cd frontend
    IIPS_NP04_DATABASE_PATH=/tmp/rel1/data/investment/investment.db \
    npx tsx server/investment/cli/generate-investment-artifacts.ts \
      --issuer         IN:CIN:L85110KA1981PLC013115 \
      --data-dir       /tmp/rel1/data/investment/dataset \
      --identity-dir   /tmp/rel1/data/investment/identity \
      --db             /tmp/rel1/data/investment/investment.db \
      --owner-carrier  /tmp/rel1/reports-owner-context.json \
      --generated-at   2026-11-06T00:00:00.000Z \
      --out            runs/cli-v1-created-pre-fix.json

Observed: `status OK`, `persist CREATED (wrote)`, `verify chain valid: 1 version(s), head v1`.
This summary is kept verbatim because it is the **D-1 evidence**: its `limitations[]` calls the dataset synthetic
while the run is reading real disclosures.
