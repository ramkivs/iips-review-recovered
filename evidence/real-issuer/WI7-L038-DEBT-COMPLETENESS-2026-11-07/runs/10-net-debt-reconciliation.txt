## What the governed path actually does

  capitalStructure.ts: cashAndInvestments = sum([cash, liquidInvestments])   line 224
                       netDebt           = subtract(grossDebt, cashAndInvestments)   line 225
  The same-instant rule is enforced by grossDebtOf() over the four DEBT components only; the cash side is
  summed from whatever periods it resolves to and is never compared with the debt periods. On Marico it
  never bites: grossDebt is already NOT_COMPUTABLE/PERIOD_MISMATCH, so subtract() returns the blocked minuend
  and no net-debt number is published.

  Consequence: relaxing only the debt-side rule (contract question option (a) as originally worded) would
  publish 608 − 487 = +121 crore, because the code would still use the 2024 cash side. The −177 crore figure
  in this bundle's earlier text is not a value the governed path can produce; it is a hypothetical that also
  moves the cash side to 2023-03-31 (785 crore).

## Correction applied

  The report, the register, the tracker and determination-l038.json now state the 785 crore cash figure and
  the 2023-03-31 period next to the 608 / −177 pair, say plainly that the payload's 487 crore is a 2024-03-31
  amount, and record the cash-side period-alignment gap as a distinct, undecided finding. No code, policy,
  dataset value, payload or period-alignment rule was changed.
