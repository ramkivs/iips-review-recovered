CORRECTIONS (rev 5; both reporting-only; no integrity gate altered):
C1 - a total classifier function Get-ReadClass(read, head) maps any remote read to exactly one of: 'not-read' (empty), 'unverifiable' (UNVERIFIABLE prefix, or missing local head to compare), 'confirmed-absent' (clean empty ABSENT read), 'carries-head' (verifiable read containing the run head), 'other-head' (verifiable read at a different head). The classifier is recorded in $script:REMREAD at every read site (PHASE-9 success read, PHASE-9 reject/indeterminate consult, PHASE-10 verification read, catch post-push read). The footer's rejected/indeterminate parent now holds five mutually-exclusive arms: not-read => publication state UNKNOWN, absence NOT claimed; unverifiable => UNKNOWN with the failure quoted, absence NOT assumed; carries-head => 'non-publication CANNOT be claimed; do NOT re-push or force-update'; confirmed-absent and other-head => the non-publication claim, explicitly grounded in 'verified origin read'. No arm asserts anything when the read cannot support it.
C2 - PHASE-10 rewritten: ls-remote runs inside a try; $verifyCode = $LASTEXITCODE is captured on the immediately following line; a throw is recorded as exit -1 (failed query). If the query failed, $script:REMOTE becomes 'UNVERIFIABLE (git ls-remote exit N; partial output quoted but NEVER used for verification: [...])' and the run is Set-Blocked with 'partial output establishes NOTHING; verification state INDETERMINATE'. Verification is established ONLY when $verifyCode -eq 0 AND parsing yields exactly ONE line whose first whitespace-delimited field -eq $headSha AND whose second field -eq ('refs/heads/' + $BRANCH) ($exact -eq 1); zero matches on a successful query is the (now properly grounded) REMOTE SHA MISMATCH path; more than one match is a REMOTE ANOMALY block; PUSHSTATE = 'verified' occurs exactly once in the whole script, inside the zero-exit / exact-1 conditional, which is itself inside the still-$STATE-PASS nested gate (defense in depth). PASS bookkeeping (PHASE-11) remains structurally gated on state 'verified'.
