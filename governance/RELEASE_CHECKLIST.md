# IIPS Engineering Standards

# RELEASE CHECKLIST

**Repository:** iips-engineering-standards  
**Version:** 1.0

---

# Purpose

This document defines the mandatory release checklist for publishing engineering standards, governance documents, calibration profiles, schemas, and reference implementations within the IIPS Engineering Standards ecosystem.

No release shall be published until every applicable checklist item has been reviewed and approved.

---

# Release Scope

This checklist applies to:

- Engineering Standards (IES-005, IES-006, ...)
- Repository Governance Documents
- Calibration Profiles
- JSON Schemas
- Reference Implementations
- Release Packages

---

# Phase 1 — Documentation Review

Verify the following:

- [ ] All documents are complete.
- [ ] Internal links are valid.
- [ ] Document identifiers are correct.
- [ ] Version numbers are updated.
- [ ] Status fields are accurate.
- [ ] Changelog is current.
- [ ] Master index updated (if applicable).

---

# Phase 2 — Technical Review

Verify:

- [ ] Methodology is internally consistent.
- [ ] Architecture remains compliant with IES-005.
- [ ] No undocumented assumptions introduced.
- [ ] Calibration changes are documented.
- [ ] Formula changes are reviewed.

---

# Phase 3 — Validation

Confirm:

- [ ] Regression testing completed.
- [ ] Replay validation passed.
- [ ] Evidence generation verified.
- [ ] Compatibility assessment completed.
- [ ] Acceptance criteria satisfied.

---

# Phase 4 — Repository Review

Confirm:

- [ ] README updated.
- [ ] ROADMAP updated.
- [ ] RELEASES updated.
- [ ] Versioning policy followed.
- [ ] Release notes prepared.
- [ ] Git tag planned.

---

# Phase 5 — Arena Readiness

Before inviting Arena AI:

- [ ] Standards published.
- [ ] Repository structure finalized.
- [ ] Onboarding guide current.
- [ ] Clarification workflow documented.
- [ ] Implementation specification available.

---

# Phase 6 — Publication

Complete:

- [ ] Merge approved.
- [ ] Release branch finalized.
- [ ] Git tag created.
- [ ] GitHub Release published.
- [ ] Release package archived.
