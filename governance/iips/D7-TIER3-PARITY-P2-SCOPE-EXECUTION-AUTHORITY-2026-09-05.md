## 6. Review-question framework (fixed by this authority; per-engine execution applies it per document)

- R2 Internal consistency: the document contains no internal contradictions and uses its own terms and definitions consistently.
- R3 Frozen-asset consistency: every checkable quantitative or factual claim in the document is consistent with the engine's P1-verified frozen assets (calibration JSON, golden reference, expected outputs, replay dataset, ontology metadata) at the pinned baseline; exact values are cross-checked wherever the document makes a checkable claim.
- R4 Methodology alignment: the document is consistent with the engine methodology ACCEPTed under D25 (D16 v1.0 / D17 v1.0 / D20 v1.0) and with W8 (existing A1 methodology preserved; no Tier-3-specific exception).
- R5 Traceability: normative and quantitative claims are traceable to frozen evidence or durably recorded governance records; any untraceable claim is registered, not accepted.
- R6 Labelling and status compliance: readiness/certification language complies with D25/D15 labelling (frozen recorded tables, not maintainer-issued certification); Class A / maturity A2 status is preserved; no A2->A1 implication.

Verdict rules (fail-closed, identical in substance to P1 S4): every question is answered PASS / FAIL / UNVERIFIABLE with cited evidence (path + blob id + ref). PASS never rests on existence or count (W5); FAIL is recorded on any substantiated contradiction; UNVERIFIABLE is recorded whenever the required evidence class is absent - never inferred away, never satisfied by existence.
