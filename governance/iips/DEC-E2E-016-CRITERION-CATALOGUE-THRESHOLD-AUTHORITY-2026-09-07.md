## Part E — A2 aggregate threshold

A2 is adopted.

The aggregate result is determined from per-criterion outcomes plus an explicit limitation registry.

An aggregate **READY WITH QUALIFIED LIMITATIONS** is permissible only when:

1. all determinable criteria are satisfied;
2. every non-PASS item is explicitly classified;
3. each accepted limitation is mapped to D3.1-A, D3.2-A, or D3.3-A;
4. each unmet requirement is explicitly stated as unmet;
5. no unqualified GO depends on an absent fact;
6. no determinable capability has an admitted conclusive breach;
7. all B2 preservation constraints remain intact.

**FAIL:** A properly admitted conclusive breach of a determinable criterion blocks the affected scope. If the adopted aggregate acceptance rule makes such a failure globally blocking, the later D6 acceptance determination must state that explicitly.

**UNRESOLVED:** UNRESOLVED blocks an unqualified GO where it affects determinability or where a required input is unresolved. An unresolved item must never be silently converted into PASS.

**QUALIFIED LIMITATION:** May coexist with a qualified aggregate outcome only when explicitly accepted, D3-mapped, visible in the limitation registry, and not relied upon for an unqualified GO.

**CURE:** No blanket cure prerequisite is established. Existing limitations remain limitations unless separately cured under their own authority.
