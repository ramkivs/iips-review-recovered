# Runbook 09 — Sequence 8: W13 actual position valuation and coverage verification

**Script:** `08-w13-valuation-verify.ps1` → `stl-host-verify.ts --mode w13`

## 1. Objective
Verify actual per-position valuation and coverage over the captured revision using the
actual W06 observations: produce the W13 `PositionValuationReport`
(`iips.w13.position-valuation/v1`) and the W20 gate output (`iips.w20.monetary-coverage-gate/v1`)
from `frontend/server/investment/positionValuation.ts` + `w20MonetaryCoverageGate.ts`.

## 2. Repository locations
IRR: `frontend/server/investment/positionValuation.ts` (closed status vocabulary; null-never-zero;
per-currency no-sum; revision-bound fail-closed), `w20MonetaryCoverageGate.ts`; runner
`tools/windows/snapshot-to-live/stl-host-verify.ts`. Inputs: step-06 package's LOCAL-ONLY exact
capture (never leaves the host) + step-04 `output/observations`.

## 3. Input identification
Newest `exact-owner-bound-portfolio-capture.json` and newest `observations/` dir under the
evidence root (located automatically); optional `-ThetaM <n>` — an **injected test parameter
only**; production θM is UNESTABLISHED.

## 4. Prerequisites
Steps 02/06 (capture) and 04 (observations) PASS; `frontend` deps installed (`npm ci`).

## 5. Runtime requirements
None — the runner reads only files named on the command line and makes no live calls.

## 6. Startup instructions
None (no services). Run from the IRR repo root.

## 7. Basic checks
Both input paths exist (script checks and reports BLOCKED naming the missing one).

## 8. Execution procedure
```powershell
cd C:\tmp\iips-review-recovered\tools\windows\snapshot-to-live
powershell.exe -NoExit -ExecutionPolicy Bypass -File .\08-w13-valuation-verify.ps1
# internally: npx tsx tools\windows\snapshot-to-live\stl-host-verify.ts --mode w13 `
#   --capture-exact <exact> --observations-dir <obs> --out <pkg>\output [--thetaM n]
```
The runner builds the `CapturedRevisionRef` from the exact capture, injects readers that serve
the saved quote/freshness responses (one per resolved identity, matching `RevisionCoverageReaders`),
runs `measureDhanRevisionCoverage` (w06 report) and `measurePositionValuation` (w13 report),
then `evaluateMonetaryCoverageGate(report, {thetaM?})`.

## 9. Scripts / invocation
`08-w13-valuation-verify.ps1 [-ThetaM ''] [-TimeoutSeconds 600]`.

## 10. Expected output
`w06-coverage-report.json`, `w13-valuation-report.json` (every position in the closed
vocabulary; valued positions carry verbatim asOf/receivedAt/evaluatedAt, currency, provenance;
unvalued are null), `w20-gate-output.json` (result BLOCKED with
`THETA_M_UNESTABLISHED` unless `-ThetaM` given; `DENOMINATOR_INDETERMINATE` while any active
position is unvalued — per V20).

## 11. Evidence capture
`08-W13/<id>/output/` — only derived, sanitized reports go to G: (the exact capture stays local).

## 12. Evidence validation
`w13-report-ok`, `closed-vocabulary`, `null-never-zero`, `theta-status-honest`,
`w20-blocked-honest` checks; manifest verify. Sandbox-proven: synthetic capture with
10×250.5 → VALUED 2505, coverage 86.38% vs stored 2900, gate BLOCKED
DENOMINATOR_INDETERMINATE + THETA_M_UNESTABLISHED.

## 13. Result classification
PASS = runner exit 0 + report validates; BLOCKED = capture or observations missing (names the
missing input and the steps to run); FAIL otherwise.

## 14. Downstream impact
PASS unblocks **W14 aggregation inputs**, **W16 lineage/readback (step 11)**, **W17 ACTUAL-mode
verification (step 12)**. W20 gate acceptance stays BLOCKED until θM is established from
W05/W06 actual evidence — synthetic-parameter verdicts are not acceptance.

## 15. Unsuccessful / unavailable evidence
- Missing capture → BLOCKED, resume = run 02/06. Missing observations → BLOCKED, resume = run 04
  (W13 actual valuation is then impossible; only synthetic verification exists, which is
  explicitly not live coverage). Runner exit 3 names the missing input file. Existing packages
  are reused when their manifests verify; a new capture is needed only on revision change.
