## 3. D1-B — EXACT GOVERNED-OBJECT DEFINITION (VERBATIM)

3.1 The following is the exact definition supplied and approved by the Program Authority. It is reproduced **verbatim**, with **no** paraphrase, normalization, correction, expansion, shortening, commentary, label prefix, or combination with the G-O-3 option description:

```text
The governed object is the active non-production IIPS feature baseline: the authoritative logical representation of the set of IIPS product capabilities and feature surfaces that are recognized as constituting the active non-production product baseline at a given point in the program. The governed object is distinct from any repository, branch, commit, implementation artifact, runtime realization, or individual workstream record; those may provide evidence of or realize the baseline but do not by themselves define the governed object.
```
