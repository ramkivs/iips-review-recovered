The retired alias pin `70b24f0` carried an IPD manifest with **no `files` field**, so npm packed
the whole repository and IRR compiled the alias's *raw TypeScript sources* into `.cache/broker-import`
via `tsconfig.broker-import.json`. The merged commit carries the DB-C1 package redesign:

```text

7bcae35 package.json : files = ["dist/package"]   exports = ./portfolio-ui, ./pit,
                                                          ./d114-non-production, ./operator-drop
```

Advancing the pin therefore removed every input of the raw-source compile. Measured, not inferred:


publish only `dist/package`, so the alias must not be silently advanced without an authorized
package/build redesign"). The redesign below is IRR-owned and touches no IPD file.

## 5. One property discovered by measurement, recorded rather than papered over

P04 quarantine record ids are minted per lookup instance by the IPD-owned pipeline
(`ident-quar-<epochMillis>-<random>`), so they are **process-specific**. Consequences:

* The evidence record's `recordDigest` is therefore not reproducible by *rebuilding* the same
  import in a new process.
* It **is** stable where it matters: the journal is dedup-keyed on
  `importId = sha256(broker ‖ contentDigest ‖ readAt)`, so the **first** retention is authoritative
  and a repeated import is a no-op that returns the stored record with its original digest.
  `brokerImportEvidenceRestart.test.ts` proves this across three separate OS processes.

The separate-process writer harness previously compared the read-back digest against a *freshly
built* record. On the first retention that is a genuine round-trip proof and is retained. On a
duplicate retention it would assert a false property, so the harness now compares against the
authoritative retained record **and** additionally proves that every stable field of the freshly
built record still matches what is durably stored (all fields except the volatile quarantine ids
and the digest derived from them). This is recorded as a limitation inside every evidence record.
