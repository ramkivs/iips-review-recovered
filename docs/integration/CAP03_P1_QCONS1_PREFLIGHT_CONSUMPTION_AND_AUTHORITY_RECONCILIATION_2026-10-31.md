## Revision 7 source findings

The reviewed merged Revision 7 implementation has one `Invoke-ExecuteClaim` call in the Execute branch and one guarded `--mode=execute` process-start site. Preflight branches around claim acquisition, marker creation, recheck-for-Execute and the `--mode=execute` call. Its S05 check invokes the entrypoint only with `--mode=validate` and expects a missing-store refusal without store creation. The S01 `node:sqlite` probe loads the module without opening a database. These are source findings only; no PowerShell parse or host run was made.

If separately authorized in future, Preflight is not effect-free: after S00 and exact-root checks it creates a unique `p1-pre-*` directory and writes a log, command/stdout/stderr/code/timing captures, a temporary sqlite-probe module, summary/failure summary, and a final `SHA256SUMS.txt` seal. It also performs local read-only Git checks and read-only GitHub API pin queries, including an IPD commit/tree query; no IPD checkout, dependency install, build, or write is in this mode. A sealed `p1-pre-*` directory is allowed by the prior-run scan. A prior unsealed `p1-*` directory is fail-closed and blocks subsequent runs, including Execute. A retained Execute claim, if one already exists, is neither released nor removed by Preflight.

**Failure and interruption:** before run-directory creation, a caught stop writes no run record. After directory creation, the normal catch attempts `failure-summary.json` and then the seal; if both succeed, the failed Preflight remains sealed and can be followed by another technically eligible Preflight, subject to all other gates. Abrupt termination can bypass the catch or interrupt the seal; the resulting unsealed directory blocks later runs. Neither case creates an Execute claim/marker or consumes P1-F. A successful sealed Preflight does not itself block a later Execute, but this record grants no Execute authority and does not establish any runtime gate.

The source header's older statement that no canonical Q-EV root was designated and both modes fail for that reason is stale: the effective Q-EV act designates `H:\IIPS-P1-EVIDENCE`, and the current script is bound to that designation. The actual outstanding boundary for standalone Revision 7 Preflight is authority, not root designation.
