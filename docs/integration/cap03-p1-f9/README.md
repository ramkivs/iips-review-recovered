This is distinct from the non-elevated directory junction that did succeed. The runner uses Windows PowerShell 5.1 `New-Item -ItemType SymbolicLink` and catches inability to create the link as unavailable; verify that exact cmdlet succeeds on the selected test host rather than inferring capability from OS version alone. A junction does not exercise the file-entry check.

The PA considered the capable-host/privilege alternatives and waived this fixture-coverage branch for the stated personal non-production scope.
