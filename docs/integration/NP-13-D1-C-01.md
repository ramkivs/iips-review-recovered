## 2. ESTABLISHED IDENTITY-BOUNDARY SEMANTICS

The following six semantics are established:

1. **Authoritative logical representation.** The governed object is an authoritative logical representation.
2. **Distinctness.** The governed object is distinct from repository, branch, commit, implementation artifact, runtime realization, and individual workstream record.
3. **Evidence and realization boundary.** Evidence or realization artifacts do not themselves define the governed object.
4. **Evidence-pin boundary.** Evidence-pin identity ≠ governing-object identity.
5. **Runtime boundary.** Governance identity ≠ runtime identity.
6. **No inferred attached identity.** No principal / tenant / company / runtime / persistence identity attaches to the governed object merely by inference.

These are boundary semantics. Except for the boundary established by this section, they do not create an otherwise unstated positive identity mechanism.
