# Program v3.0 — Design Principles

**Program:** IIPS Engineering Standards — Program v3.0
**Document type:** DESIGN PRINCIPLES (Phase 1)
**Version:** 1.0
**Date:** 2026-08-09

> Global UX/design principles governing the v3.0 design system and components.

---

## 1. Design language

- **Institutional, analytical, trustworthy, precise, modern.**
- Information-dense but readable; serious financial research; enterprise-grade.
- Prioritize **information hierarchy** over decoration.

## 2. Avoid

- Consumer-fintech visual language.
- Excessive gradients.
- Decorative dashboards.
- Meaningless animations.
- Oversized cards.
- Excessive rounded containers.
- Arbitrary colors.
- Visual noise.

## 3. Information hierarchy

- **Decision before metric** (P2).
- **Progressive disclosure** (P6): L1 summary → L5 raw.
- Status communicated with **non-color-only** indicators (icon + text + color).

## 4. Truth & authority

- Certified results visually distinct from AI explanations.
- Data freshness and provenance always visible where available.
- Never present stale/unavailable data as current; show **"Data unavailable"** instead of fabricated values.

## 5. Semantic status palette

Concepts to encode: Positive, Negative, Neutral, Warning, Critical, Informational, Certified, Pending, Unavailable, Stale. **Never encode business meaning through color alone.**

## 6. Accessibility (base requirement)

- Keyboard navigation, visible focus, semantic HTML, ARIA.
- Screen-reader labels, accessible tables/charts.
- Non-color-only status, adequate contrast, reduced-motion support.

## 7. Density & responsiveness

- Designed for desktop/enterprise workstation (primary) and tablet (secondary); mobile usable but not full density.
- Intentional responsive behavior — not simple shrinking.
