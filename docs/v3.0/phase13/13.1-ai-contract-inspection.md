## 1. Actual `AiAssistedRuntime` contract (inspected from `iips-platform/src/distributed/AiAssistedRuntime.ts`)

### The advisory output type
```ts
export interface AiAdvice {
  readonly kind: 'explanation' | 'summary' | 'hypothesis' | 'anomaly' | 'research';
  readonly text: string;
  readonly grounded: boolean;        // every claim traces to platform evidence
  readonly nonAuthoritative: true;   // never a decision
  readonly model: string;
  readonly modelVersion: string;
  readonly engineResultRef?: string; // link to the certified engine result
}
```

### The advisor contract
```ts
export interface AiAdvisor {
  advise(engineResult: ExecutionResult, evidence: Record<string, unknown>): AiAdvice;
}
```

### The runtime facade (public methods)
```ts
executeWithAi(engineId, makeEngine, request)
  -> { result: ExecutionResult; advice: AiAdvice; engineResultUnchanged: true }
executeWithoutAi(engineId, makeEngine, request) -> ExecutionResult
isEngineResultEquivalent(a, b) -> boolean
adviceLog() -> readonly AiAdvice[]
```

### Deterministic lineage helper
```ts
adviceId(input: string): string   // FNV-1a, deterministic
```

## 4. Conclusion
The `AiAssistedRuntime` contract is a **read-only, non-authoritative, deterministic, evidence-grounded
advisory facade** with **no tenant, no native governed audit, no RBAC coupling, no persistence, no
external provider, and no configuration surface**. It **can** be exposed safely as a read-only AI
Explanation surface — **but only via a server-side `SecuredExecutor` wrapper** that supplies the
missing tenant enforcement + governed audit (see the authority/security map). It must be clearly
labeled **AI EXPLANATION ≠ CERTIFIED RESULT**, and fields the contract does not carry
(timestamp, tenant, provider, confidence, decision) must be shown as **UNAVAILABLE** — never
fabricated.
