source → authority → read/write → tenant → audit → status.**

## Source-of-truth rule
Every displayed field maps to a governed source. Missing fields render **UNAVAILABLE** — never a
fabricated `0`, confidence, model identity, citation, timestamp, tenant, or decision. AI is never a
decision authority; `BUY/SELL/HOLD/CERTIFIED/APPROVED` must come only from the certified governed
engine result, never from `AiAssistedRuntime`.
