# PROGRAM v3.0 — Phase 13.1: AI Authority & Security Map

Maps the authority boundary for a future read-only AI advisory surface. **Inspection/design only —
no implementation.**

## AI authority boundary (frozen)
```
CERTIFIED RESULT  ≠  AI EXPLANATION
```
- AI may **explain** a certified result.
- AI may **NOT** replace or alter it (A===B flagship invariant).
- AI is **never** a decision authority; `BUY/SELL/HOLD/CERTIFIED/APPROVED` must come only from the
  certified governed engine result, not `AiAssistedRuntime`.

## Required authority chain (for a future advisory endpoint)

```
Keycloak (WHO)
  → OIDC → ValidatedIdentity
  → EnterpriseRuntime.Principal
  → Tenant resolution/validation (TenantDirectory, platform-validated)
  → SecuredExecutor.authenticate (401)
  → SecuredExecutor.authorize (EnterpriseRuntime RBAC + gate) (403)
  → server-side tenant validation
  → governed audit (allow/deny)
  → AiAssistedRuntime (advise/executeWithAi on the certified engine result)
  → G2 DTO (read-only, non-authoritative)
  → React (presentation only; AI EXPLANATION label)
```

## Gap: AiAssistedRuntime has NO tenant/audit semantics
Verified: `AiAssistedRuntime`/`AiAdvice` have **no `tenantId`, no EnterpriseRuntime/PlatformApi/
ApiSecurity reference, no `AuditRecord`**. Therefore a **server-side wrapper is required**:

| Property | Supplied by | Required |
|---|---|---|
| Authentication | `SecuredExecutor.authenticate` | ✅ |
| RBAC authorization | `SecuredExecutor.authorize` (EnterpriseRuntime) | ✅ |
| Tenant enforcement | server-side (request tenant context; `isTenantResource`/directory) | ✅ (wrapper) |
| Governed audit | `EnterpriseRuntime.check` / wrapper allow+deny | ✅ (wrapper) |
| Freshness | DTO/transport label (LIVE/SNAPSHOT/STALE/UNAVAILABLE/REPLAY) | ✅ (transport) |

## Prohibited (never)
- localStorage authorization · client-controlled tenant · frontend RBAC · ad-hoc JWT · second audit
  system · second permission system · AI-as-decision · AI config/prompt/provider exposure.

## Semantic boundary (mandatory label)
Any future AI UI must render **"AI EXPLANATION ≠ CERTIFIED RESULT"** (using the existing
`AiBadge`/authority badges) and show the `grounded` flag. It must never blend AI output with the
certified result surface.
