# PROGRAM v3.0 — Phase 13.3: Platform Operations Read Contract Inspection

**Status:** CONTRACT INSPECTION — COMPLETE (documentation only; **no implementation**)

**Baseline:** `v3.0-phase12-certified` (immutable) + Phase 13.1/13.2 AI advisory (certified).
No tag/baseline/v1.1/v2.0/G3/Phase12/13.2 semantics modified. No code/package/platform change.

---

## 1. Objective
Determine whether a read-only **Platform Operations** surface is genuinely governed and safe to
expose, covering: HA/node health, DR/backup status, telemetry, performance measurements, and the
existing migration/workflow/marketplace read state. Apply the same rules as prior phases.

## 2. Key finding (important)
**Platform Operations read is ALREADY exposed in Phase 12.1 Administration.**
`frontend/server/admin-transport.ts` already serves, behind `guardAdmin` (admin-only, G3-enforced):

| Endpoint | Governed source | Admin-gated |
|---|---|---|
| `/api/admin/platform` | `CloudHaRuntime` / `DisasterRecoveryRuntime` / `V2Observability` / `PerformanceScaling` | ✅ |
| `/api/admin/migration` | `MigrationRuntime.migrationsLog` | ✅ |
| `/api/admin/workflow` | `WorkflowRuntime` (definitions) | ✅ |
| `/api/admin/marketplace` | `PluginMarketplace.list` | ✅ |
| `/api/admin/certification` | `PluginMarketplace` (cert) | ✅ |

The Phase 13.3 question is therefore **not "does it exist"** but whether a **broader / non-admin
read-only Platform Operations surface** is warranted, and whether each read is genuinely governed +
safe. Inspection concludes: the governed read contracts exist and are read-safe; no new mutation or
lifecycle control should be added.

## 3. HA / node health — inspected
- `CloudHaRuntime.checkHealth(nodeId): NodeHealth` (`healthy|degraded|down`) — READ ✅.
- `CloudHaRuntime.coordinator(): string|null` — READ ✅.
- `CloudHaRuntime.nodeCount(): number` — READ ✅.
- **Mutation-capable (NOT read):** `markDown`, `rollingRestart`, `register`, `place`, `execute` —
  keep OUT of scope (lifecycle/HA operations).

## 4. DR / backup status — inspected
- `DisasterRecoveryRuntime.exportBackup(node): DrBackup` — READ ✅ (produces backup record).
- `DisasterRecoveryRuntime.detectCorruption(backup, node): string[]` — READ ✅.
- `DisasterRecoveryRuntime.measureRpoRto(backup, node, replayFn)` — READ ✅.
- **Mutation-capable (NOT read):** `restore` — keep OUT of scope (destructive DR operation).

## 5. Telemetry — inspected
- `V2Observability.list(): readonly TraceRecord[]` — READ ✅.
- `V2Observability.byTrace(traceId): TraceRecord[]` — READ ✅.
- **Mutation-capable (NOT read):** `clear()` (resets telemetry), `record*` (ingestion by pipeline) —
  keep OUT of scope.

## 6. Performance measurements — inspected
- `PerformanceScaling.measureBatch(...): ScalingSample` — READ/measurement ✅.
- `PerformanceScaling.measureFullChain(...): ScalingSample` — READ/measurement ✅.
- Returns `nodes, executions, elapsedMs, throughputPerSec, p50Ms, p95Ms, meanMs` (measured, not SLA).

## 7. Existing migration / workflow / marketplace read state — inspected
- `MigrationRuntime.migrationsLog(): readonly MigrationRecord[]` — READ ✅ (already exposed in admin).
- `WorkflowRuntime.version(workflowId)` — READ ✅; `WorkflowRuntime.execute(...)` executes (NOT read —
  keep out of scope unless a governed run surface is separately authorized).
- `PluginMarketplace.list(): PluginRecord[]` / `get(pluginId)` — READ ✅ (already exposed in admin).
- **Mutation-capable (NOT read):** `recordMigration`, `register`, `revoke`, `define`, `execute`.

## 8. Read-vs-mutation inventory (what stays out of Phase 13.3)

| Module | READ (safe, governed) | MUTATION (keep out of scope) |
|---|---|---|
| `CloudHaRuntime` | `checkHealth`, `coordinator`, `nodeCount` | `markDown`, `rollingRestart`, `register`, `place` |
| `DisasterRecoveryRuntime` | `exportBackup`, `detectCorruption`, `measureRpoRto` | `restore` |
| `V2Observability` | `list`, `byTrace` | `clear`, `record*` |
| `PerformanceScaling` | `measureBatch`, `measureFullChain` | — |
| `MigrationRuntime` | `migrationsLog` | `recordMigration`, `execute` |
| `WorkflowRuntime` | `version` | `define`, `execute` |
| `PluginMarketplace` | `list`, `get` | `register`, `revoke`, `certify`, `verifyDeterminism` |

## 9. Conclusion
Platform Operations read is **genuinely governed and read-safe**, and is **already exposed** in the
Phase 12.1 Administration surface (admin-gated, G3-enforced). A Phase 13.3 implementation would add
**no new governed capability** unless it introduces a **non-admin read surface** or a dedicated
read-only Platform Operations workspace outside Administration — a product/IA decision, not a
governed-contract gap. No lifecycle mutation (markDown/restart/restore/activation) should be exposed.
