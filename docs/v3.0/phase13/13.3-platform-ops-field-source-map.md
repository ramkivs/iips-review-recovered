# PROGRAM v3.0 — Phase 13.3: Platform Operations Field → Source Map

Every proposed Platform Operations field mapped: **UI field → G2 DTO → governed contract →
certified source → authority → read/write → tenant → audit → status.**
Convention — **Status:** ✅ AVAILABLE · ⚠️ PARTIAL · ❌ UNAVAILABLE (no governed source — never fabricate).

| UI field | G2 DTO | Governed contract | Source | Authority | R/W | Tenant | Audit | Status |
|---|---|---|---|---|---|---|---|---|
| Node id | `nodes[].nodeId` | `CloudHaRuntime` | HA registry | Platform | READ | global | ⚠️ | ✅ |
| Node health | `nodes[].health` | `checkHealth` | HA registry | Platform | READ | global | ⚠️ | ✅ |
| HA coordinator | `ha.coordinator` | `coordinator()` | HA registry | Platform | READ | global | ⚠️ | ✅ |
| Node count | `ha.nodeCount` | `nodeCount()` | HA registry | Platform | READ | global | ⚠️ | ✅ |
| DR backup id | `dr[].backupId` | `exportBackup` | DR runtime | Platform | READ | global | ⚠️ | ✅ |
| DR lineage | `dr[].lineage` | `exportBackup` | DR runtime | Platform | READ | global | ⚠️ | ✅ |
| DR snapshot count | `dr[].snapshotCount` | `exportBackup` | DR runtime | Platform | READ | global | ⚠️ | ✅ |
| Trace id / event / node | `telemetry[].traceId/event/nodeId` | `V2Observability` | telemetry | Platform | READ | global | ✅ | ✅ |
| Throughput / p50 / p95 | `performance` | `PerformanceScaling.measureBatch` | measurement | Platform | READ | global | ⚠️ | ✅ |
| Migration history | `migration.migrations[]` | `MigrationRuntime.migrationsLog` | governed migration | Platform | READ | global | ✅ | ✅ |

> **Rule:** governed read fields map 1:1; absent fields (uptime%, SLO, capacity) render
> **UNAVAILABLE** — never fabricated. Lifecycle/restore controls are NOT read fields and stay out of
> scope.
