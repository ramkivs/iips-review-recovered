# PROGRAM v3.0 — Phase 13.1: AI Advisory Recommendation

**Status:** CONTRACT INSPECTION + G2 DESIGN — COMPLETE (no implementation)

## Verdict
A **read-only AI explanation surface can be exposed safely in v3.0**, provided it is:
1. wrapped by the server-side `SecuredExecutor` (supplying the missing tenant + governed audit),
2. read-only and **non-authoritative** (AI EXPLANATION ≠ CERTIFIED RESULT),
3. source-of-truth mapped (no fabricated timestamp/tenant/provider/confidence/decision),
4. authorized as a separate milestone (Phase 13.2).

## What the governed contract actually provides (verified)
- `AiAdvice`: kind, text, grounded, nonAuthoritative(true), model, modelVersion, engineResultRef?.
- Deterministic, evidence-grounded, A===B (AI does not alter the certified result), failure-isolated.
- **No** tenantId, timestamp, provider/config, confidence, citations, decision; **no** native governed
  audit; **no** RBAC coupling; **no** external provider configured; **no** mutation/config surface.

## Recommended Phase 13.2 scope (ONLY after explicit authorization)
1. **G2 read-only AI advisory endpoint** (`GET /api/ai-advisory/:engineResultId`) — via the frozen
   chain (Keycloak → SecuredExecutor → RBAC → tenant → governed audit → AiAssistedRuntime → DTO).
2. **G1 AI Explanation UI** — non-authoritative advisory, "AI EXPLANATION ≠ CERTIFIED RESULT" label,
   grounded flag, model/version, engine-result link; freshness + unavailable fields.
3. **No new mutation, no AI config/prompt/provider, no decision recommendation.**

## Mutation boundary (confirmed — NOT exposed)
No model selection, prompt editing, provider configuration, temperature/config, AI policy editing,
enable/disable, approval workflow, or AI-generated investment decision. These remain UNAVAILABLE
unless a separate platform-governance contract exists.

## Explicit UNAVAILABLE fields
timestamp, tenantId (on advice), provider/config, AI confidence, citations, decision/recommendation,
AI configuration/governance.

## Whether G2 implementation is safe
**YES (design-safe):** read-only, deterministic, non-authoritative, evidence-grounded; wrappable by
`SecuredExecutor` for tenant + audit; no external provider; no mutation. **But do not implement until
Phase 13.2 is explicitly approved.**
