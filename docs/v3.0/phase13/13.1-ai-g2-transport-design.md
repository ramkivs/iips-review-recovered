# PROGRAM v3.0 — Phase 13.1: AI Advisory G2 Transport Design

Design for a future read-only AI advisory endpoint. **DESIGN ONLY — NOT implemented.** No existing
governed endpoint already exposes AI advisory, so a new one is warranted if authorized.

## Proposed endpoint (conceptual — do NOT implement yet)
```
GET /api/ai-advisory/:engineResultId
```

> Route semantics: advisory for a **certified engine result** (identified by `:engineResultId` =
> the certified result/snapshot identity). No existing `/api/*` endpoint returns `AiAdvice`, so this
> is a new read-only surface — not a duplicate.

## Request identity & tenant resolution
- `:engineResultId` = the certified engine result/snapshot ref the advice explains.
- **Tenant is NOT in the URL/query.** It is resolved server-side from the authenticated
  `EnterpriseRuntime.Principal` + platform `TenantDirectory` (never from client/URL/header/state).

## Exact DTO (read-only, non-authoritative)
```ts
interface AiAdvisoryDto {
  adviceId: string;                 // deterministic adviceId (FNV-1a) over the request identity
  engineResultId: string;           // :engineResultId (certified result being explained)
  kind: 'explanation'|'summary'|'hypothesis'|'anomaly'|'research';
  text: string;
  grounded: boolean;
  nonAuthoritative: true;           // always true
  model: string;
  modelVersion: string;
  engineResultRef?: string;         // may be absent
  label: 'AI EXPLANATION ≠ CERTIFIED RESULT';  // mandatory semantic marker
  freshness: 'LIVE'|'SNAPSHOT'|'STALE'|'UNAVAILABLE'|'REPLAY';  // transport-supplied
  unavailable: readonly string[];   // fields intentionally not provided (e.g. ['timestamp','tenant'])
}
```

## Source mapping
| DTO field | Source |
|---|---|
| adviceId | `AiAssistedRuntime.adviceId` (deterministic) |
| engineResultId | request param |
| kind/text/grounded/nonAuthoritative/model/modelVersion/engineResultRef | `AiAdvice` (governed) |
| label | constitution (advisory-only) |
| freshness | transport provenance (`AdminProvenance`-style) |
| unavailable | documented absent fields |

## Error semantics
- `401` — unauthenticated (missing/invalid/expired Keycloak).
- `403` — authenticated but unauthorized, or cross-tenant.
- `404` — `:engineResultId` not found / not accessible to tenant.
- `5xx` — platform/transport failure.
- Never expose sensitive provider/model internals.

## 401/403 & audit behavior
- Through the frozen chain: `SecuredExecutor.authenticate` (401) → `authorize` (403) → tenant
  validation → governed allow/deny audit (EnterpriseRuntime).

## Freshness & unavailable behavior
- Freshness labeled by transport (LIVE/SNAPSHOT/STALE/UNAVAILABLE/REPLAY).
- Fields absent from the governed contract (timestamp, tenant, provider, confidence, citations,
  decision) render **UNAVAILABLE** — never fabricated.

## Safety verdict
A G2 read-only AI advisory endpoint **is safe to design**, because:
1. `AiAssistedRuntime` is read-only, deterministic, non-authoritative, evidence-grounded (A===B).
2. It can be wrapped by `SecuredExecutor` for the missing tenant + audit.
3. No mutation/config/provider surface is exposed.
4. AI output stays clearly labeled non-authoritative.

**Do NOT implement it until Phase 13.2 is explicitly authorized.**
