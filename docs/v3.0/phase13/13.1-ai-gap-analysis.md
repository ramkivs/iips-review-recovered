# PROGRAM v3.0 — Phase 13.1: AI Gap Analysis

Gap classification: **G1** UI gap · **G2** transport gap · **G3** platform contract gap ·
**G4** governance/security gap (HARD STOP) · **G5** data-source gap.

| Gap | Desired | Actual | Class | Action |
|---|---|---|---|---|
| AI explanation UI | Non-authoritative advisory per engine result | `AiAdvice` governed; no v3.0 UI | **G1** | Potential Phase 13.2 UI (read-only) |
| AI advisory G2 transport | read-only endpoint | `AiAssistedRuntime` not exposed via G2 | **G2** | Potential G2 read endpoint (Phase 13.2) |
| Timestamp / freshness on advice | show when generated | ❌ no field on `AiAdvice` | **G3** (platform) | transport-supplied freshness; not invented |
| tenantId on advice record | tenant attribution | ❌ no field | **G3** (platform) | tenant from request context (wrapper); not on advice |
| Provider name / config | provider identity/config | ❌ none (deterministic in-process advisor) | **G3** | UNAVAILABLE (no external provider configured) |
| AI confidence / citations / decision rec | AI confidence/recs | ❌ none (non-authoritative by design) | **G5** (by design) | UNAVAILABLE / forbidden |
| Native governed audit on advice | audited AI reads | ❌ `adviceLog` is plain, not `AuditRecord` | **G3** (platform) | wrapper emits governed audit; not a second audit system |
| AI configuration / model / prompt editing | admin surface | ❌ no contract | **G3** | UNAVAILABLE (mutation boundary) |

## Classification summary
- **G1:** 1 (AI explanation UI) · **G2:** 1 (AI advisory G2 read endpoint) · **G3:** 4 (timestamp,
  tenant-on-record, provider, native audit) · **G4:** 0 (no HARD STOP) · **G5:** 1 (confidence/decision —
  by-design unavailable).

## Key conclusion
- **G4 = 0:** no governance/security HARD STOP. The AI surface is read-only and wrappable by
  `SecuredExecutor` for tenant + audit.
- The clean actionable Phase 13.2 work is **G1 + G2**: a read-only AI explanation surface over
  `AiAssistedRuntime`, with freshness/provenance supplied by the transport and clearly labeled
  non-authoritative.
- **G3 gaps (timestamp, tenant-on-record, provider, native audit) are platform-contract concerns**,
  not to be fabricated in React/transport. AI config/governance remains UNAVAILABLE.
