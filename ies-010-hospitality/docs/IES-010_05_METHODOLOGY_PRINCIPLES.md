# 1. Purpose

The conceptual foundation for the Hospitality metric library and score engine. Full principles in `HOSPITALITY_METHODOLOGY_PRINCIPLES.md` (Phase 1, approved).

# 2. Invariant principles (recap)

1. RevPAR quality > revenue size.
2. Asset-light earnings quality > owned volatility.
3. Demand quality (direct/corporate/loyalty) > gross occupancy.
4. Operating leverage is double-edged (growth + risk).
5. Brand + distribution moat is foundational.
6. Deterministic, replayable, explainable — platform-neutral.

# 3. Calibration vs scoring

Cyclicality, seasonality, asset-light vs owned are **calibration** concerns (business-model thresholds/weights), not scoring-logic changes.
