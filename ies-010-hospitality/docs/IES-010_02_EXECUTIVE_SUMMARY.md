# Purpose

High-level summary of the Hospitality Sector Engine for reviewers.

# Summary

- **Sector economics:** RevPAR-centric operating engine; asset-light vs owned business models.
- **Core metrics:** Occupancy, ADR, RevPAR, GOP margin, asset-light/fee mix, leverage, RevPAR growth.
- **Methodology:** deterministic band→score→pillar→composite→verdict, calibrated by business model.
- **Moat:** brand + distribution + loyalty (maps to ontology Moat dimension).
- **Overrides:** demand shock, occupancy collapse, leverage breach, brand deterioration.
- **Platform-neutral:** differences expressed via methodology + calibration, no platform changes.

# Acceptance basis

Independent implementation must reproduce the same composite + verdict from the same inputs + calibration (Normative Calculation Appendix D15).
