# Purpose

Documents the data sources that inform the hospitality methodology and reference assets (Phase 3).

# 1. Sources

| Source | Use |
|---|---|
| Operator financial reports (public) | revenue, EBITDA, leverage |
| Industry KPIs (occupancy, ADR, RevPAR) | sector operating metrics |
| Brand/management company disclosures | fee income, pipeline |
| Company investor presentations | business-model mix, strategy |
| Regulatory/licensing records | compliance context |

# 2. Methodology data (golden dataset, Phase 3)

- Representative hospitality providers across business models (owned, managed, franchised, asset-light).
- Deterministic, versioned, evidence-backed.

# 3. Data provenance

Every reference data item carries source + version, so outputs are reproducible and evidence-backed.
