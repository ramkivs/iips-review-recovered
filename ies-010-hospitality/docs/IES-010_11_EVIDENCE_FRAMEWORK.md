# Purpose

Defines the evidence produced for every hospitality decision — deterministic, traceable, explainable.

# 1. Evidence record

Every decision produces:
- **engineId** — `sector.hospitality`
- **verdict** — final verdict
- **composite** — composite score
- **pillars** — occupancy, demand/RevPAR, growth, profitability, earnings-quality, capital/risk
- **overridesApplied** — any override + rationale
- **calibrationVersion** — business-model calibration profile used
- **methodologyVersion** — IES-010 v1.0

# 2. Why-rationale

Every recommendation explains:
- Why this RevPAR/demand quality is attractive.
- Why this asset-light / earnings quality.
- Which calibration profile (business model) applies.
- Which engine produced it (`sector.hospitality`).
- Confidence + supporting evidence.

# 3. Determinism

Evidence is deterministic + versioned; replay reproduces identical evidence.
