# Purpose

Describes the technology industry structure that the methodology models.

# 1. Value chain

```text
R&D/IP → product/platform development → distribution/cloud → customer adoption → renewal/retention (recurring) or one-time sale
```

# 2. Subsegments (economically distinct)

| Subsegment | Primary economics | Cyclicality |
|---|---|---|
| Software / SaaS | recurring, high margin | Growth |
| IT Services | services/project | Mature |
| Semiconductors | capital-intensive, cyclical | High |
| Electronics / Hardware | hardware, volume/margin | High |
| Digital Platforms | transaction/network effects | Growth |
| Internet / Consumer Tech | usage/transaction | Growth |
| Cybersecurity | recurring + services | Growth |
| Data / Infrastructure | usage/contractual | Growth |
| Tech-enabled Services | services + tech leverage | Moderate |

# 3. Business-model archetypes

License · Subscription · Usage-based · Transaction/Platform · Hardware · Foundry/Manufacturing · Services/Project · Managed Services · Hybrid.

# 4. Demand drivers

R&D intensity, product innovation, recurring revenue base, retention/NRR, switching costs, network effects, platform lock-in, customer concentration, capex (semis/hardware), cloud/usage growth.
