# Purpose

Documents the data sources that inform the technology methodology and reference assets (Phase 3).

# 1. Sources

| Source | Use |
|---|---|
| Company financial reports (public) | revenue, EBITDA, leverage, gross margin, FCF, R&D |
| Operator/subscription disclosures | recurring revenue, NRR, retention, usage |
| Market/industry data | valuation multiples, capex cycle |
| Customer/concentration disclosures | customer concentration |
| Regulatory/licensing records | privacy/security/export compliance |

# 2. Methodology data (golden dataset, Phase 3)

- Representative technology providers across subsegments + business-model archetypes (incl. Hybrid).
- Deterministic, versioned, evidence-backed.

# 3. Data provenance

Every reference data item carries source + version, so outputs are reproducible and evidence-backed.
