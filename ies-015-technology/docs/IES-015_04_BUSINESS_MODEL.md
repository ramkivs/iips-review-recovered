# Purpose

Models how technology businesses create, earn, and compound value.

# 1. Value creation

- **Durable recurring revenue** (subscription/usage/managed) — high-margin, sticky.
- **Retention / NRR** — compounding existing-base growth.
- **Gross margin** — software vs hardware/semi economics.
- **R&D / IP pipeline** — innovation → growth + moat.
- **Network effects / switching costs** — compounding moat + usage.
- **Capital discipline** — FCF yield, cash conversion.

# 2. Value destruction

- Churn / retention decline.
- Customer-concentration loss.
- Disruption / obsolescence.
- Over-spend (R&D/capex) without productization.
- Pricing pressure / margin compression.
- Cyclical semis/hardware downturn.
- Over-leverage.

# 3. Recurring-revenue semantics

Recurring revenue is a durable quality signal; NRR > 100% implies compounding existing base without new-customer spend.

# 4. Gross-margin economics

Gross margin differentiates software (high, recurring) from hardware/semis (lower, COGS/capex-heavy).
