# Purpose

High-level summary of the Technology Sector Engine for reviewers.

# Summary

- **Sector economics:** durable recurring economics × growth × capital discipline, over growth-heavy (software/platform/cloud) / cyclical (semis/hardware) / mature (IT services) bases.
- **Core metrics:** recurring revenue %, NRR/retention, revenue growth, gross margin, R&D intensity, customer concentration, FCF yield/cash conversion, capex intensity, EBITDA margin, leverage.
- **Methodology:** deterministic band→score→pillar→composite→verdict, calibrated by subsegment + business-model archetype.
- **Calibration precedence:** subsegment + archetype → calibration profile → frozen thresholds/weights → common score engine.
- **Moat:** network effects, switching costs, IP, platform lock-in (→ ontology Moat).
- **Overrides:** churn collapse, customer-concentration loss, disruption/obsolescence, capex overrun, margin compression, leverage breach, governance.
- **Platform-neutral:** differences via methodology + calibration, no platform changes.

# Acceptance basis

Independent implementation must reproduce the same composite + verdict from the same inputs + calibration (Normative Calculation Appendix D15).
