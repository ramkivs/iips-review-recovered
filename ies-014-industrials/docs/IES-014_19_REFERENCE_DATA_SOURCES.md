# Purpose

Documents the data sources that inform the industrials methodology and reference assets (Phase 3).

# 1. Sources

| Source | Use |
|---|---|
| Company financial reports (public) | revenue, EBITDA, leverage, ROCE, FCF |
| Operator order/backlog disclosures | backlog, book-to-bill, orders |
| Segment/divisional data | aftermarket mix, project exposure |
| Market/industry data | industrial production, capex cycle, defense budgets |
| Regulatory/licensing records | compliance context |

# 2. Methodology data (golden dataset, Phase 3)

- Representative industrials providers across subsegments + business-model archetypes.
- Deterministic, versioned, evidence-backed.

# 3. Data provenance

Every reference data item carries source + version, so outputs are reproducible and evidence-backed.
