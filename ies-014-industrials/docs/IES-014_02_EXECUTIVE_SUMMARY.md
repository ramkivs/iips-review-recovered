# Purpose

High-level summary of the Industrials Sector Engine for reviewers.

# Summary

- **Sector economics:** visible demand (backlog/orders) × execution quality (margins/aftermarket mix) × capital discipline, over a cyclical base.
- **Core metrics:** backlog, book-to-bill, aftermarket/services %, revenue growth, EBITDA/op margin, FCF yield, order growth, leverage.
- **Methodology:** deterministic band→score→pillar→composite→verdict, calibrated by subsegment + business-model archetype.
- **Cyclicality:** risk via calibration; valuation/margin normalized across the cycle.
- **Moat:** aftermarket/service lock-in, technology, scale, defense franchise (→ ontology Moat).
- **Overrides:** order cancellation/demand shock, EPC cost overrun, defense program failure, margin compression, leverage breach, governance.
- **Platform-neutral:** differences via methodology + calibration, no platform changes.

# Acceptance basis

Independent implementation must reproduce the same composite + verdict from the same inputs + calibration (Normative Calculation Appendix D15).
