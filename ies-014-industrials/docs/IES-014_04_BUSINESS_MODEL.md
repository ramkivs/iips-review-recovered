# Purpose

Models how industrials businesses create, earn, and compound value.

# 1. Value creation

- **Visible demand (backlog/orders)** — future revenue visibility.
- **Execution quality** — margins, aftermarket mix, program execution.
- **Aftermarket/service economics** — recurring, high-margin, counter-cyclical.
- **Low-cost manufacturing + operating leverage** — margin expansion with volume.
- **Capital discipline** — ROCE, FCF yield, capital return, M&A discipline.

# 2. Value destruction

- Order cancellations / demand shocks.
- Project / EPC cost overruns.
- Defense/aerospace program failure.
- Margin compression.
- Over-leverage.
- Value-destructive M&A.

# 3. Book-to-bill semantics

- Book-to-bill = orders ÷ shipments; >1 implies growing backlog; <1 implies shrinkage.

# 4. Aftermarket / service economics

- Recurring, high-margin, counter-cyclical service revenue diversifies cyclical equipment sales.
- Higher aftermarket mix → higher earnings quality + moat (installed-base lock-in).
